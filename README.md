# Smart Grade

โปรแกรมเก็บคะแนน เช็กชื่อ ส่งงาน และตรวจสมุด ใช้งานในเบราว์เซอร์ได้แม้ไม่มีอินเทอร์เน็ต

- ข้อมูลนักเรียนและคะแนนเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งานเท่านั้น ไม่ได้อัปโหลดขึ้นเว็บนี้
- ย้ายข้อมูลระหว่างเครื่อง: แท็บ "ตั้งค่า" → สำรองข้อมูล (.json) แล้วนำเข้าที่อีกเครื่อง
- ห้ามอัปโหลดไฟล์สำรอง .json ขึ้นที่นี่ เพราะมีรายชื่อนักเรียน
